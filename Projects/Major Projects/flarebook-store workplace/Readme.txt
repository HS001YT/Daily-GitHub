FlareBook Store - Frontend Bookstore Website



🚀 Project Overview
FlareBook Store is a modern, responsive bookstore website frontend that provides an immersive book shopping experience. 
Built with HTML5, CSS3, and Vanilla JavaScript, it features a clean dark theme with vibrant orange accents and smooth animations.



✅ Completed Pages
1. Home Page (index.html) - Featured books, hero slider, categories
2. About Page (about.html) - Company information and story
3. Login Page (login.html) - User authentication interface
4. Basic Website Structure - Consistent header, footer, and navigation



⚠️ Current Limitations
Frontend Only - No backend integration



🛠️ Under Development
1. Category Page - Browse books by genre
2. Account Dashboard - User profile management
3. Orders Page - Purchase history
4. Wishlist Page - Saved items
5. Shopping Cart - Checkout process
6. Settings Page - User preferences
