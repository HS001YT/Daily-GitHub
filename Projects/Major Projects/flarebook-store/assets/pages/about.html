Purpose of the Project

FlareBook Store is a frontend-only web application designed as a complete online bookstore experience. This project demonstrates modern web design principles, user interface best practices, and interactive features that simulate a real e-commerce platform.

The focus is on creating a seamless user experience with beautiful visuals, smooth animations, and intuitive navigation—all implemented using frontend technologies only.

Technologies Used

HTML5

Semantic structure & modern elements

CSS3

Advanced styling with CSS Grid & Flexbox

JavaScript

Interactive features & dynamic content

Local Storage

Client-side data persistence

Project Limitations

Frontend Only

No backend server or database integration. All data is stored locally in the browser.

Single User Experience

User accounts are stored locally and cannot be shared across different browsers or devices.

Limited Book Catalog

Book data is static and predefined. No real-time inventory or search from external databases.
